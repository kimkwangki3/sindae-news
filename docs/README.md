## 명세와 다르게 구현한 곳

지시서를 그대로 따르지 않은 부분이 있다. 코드 쪽 주석에 이유를 적어 뒀지만,
문서만 읽고 "왜 안 했지?" 하는 일이 없도록 여기에도 남긴다.

**주민의견조사 명세서**

- **이메일 인증 필수(7-1)** → 온보딩 완료 여부로 대체했다. 이 사이트는 카카오
  OAuth 전용이라, 카카오가 이메일을 넘기지 않은 계정은 글자 그대로 적용하면
  전원이 참여 불가가 된다. → `db/surveys-migration.sql` 의 `survey_can_vote()`
- **가입 24시간 대기(7-1 ③)** → 넣지 않았다(발행인 결정). 기사를 보고 막
  가입한 진짜 주민이 막힌다.
- **`is_admin()` 새로 만들기(2-2)** → 이미 있는 `is_staff()` 를 쓴다.
  같은 판정을 하는 함수가 둘이 되면 한쪽만 고쳐지는 사고가 난다.
- **미들웨어에서 `/admin` 검증(10장)** → 넣지 않았다. 모든 요청마다 profiles
  조회가 붙는다. 지금도 레이아웃·서버액션·RLS 세 겹으로 막고 있다.
- **거주 지구 5갈래** → 3갈래(신대지구·해룡면·그 외 지역)로 줄였다.
  설문은 답할 때마다 고르는 값이라 길면 '선택 안 함'으로 넘어간다.
- **`ip_hash` 90일 삭제(1-4)** → 나중에 붙였다. `db/survey-ip-cleanup-migration.sql`

**구글색인 지시서**

- 목록 2쪽 이상은 `?p=2` 를 그대로 canonical 로 둔다. 문서에는 없던 처리다.
  파라미터를 전부 기본 경로로 몰면 2쪽 이하가 색인에서 통째로 사라진다.
