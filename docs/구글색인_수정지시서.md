# sdtime.net 구글 색인 수정 지시서

대상: VS Code (Claude Code) 작업용
작성일: 2026년 8월 10일
프로젝트: Next.js (App Router) + Supabase, Vercel 배포
우선순위: **최상 — 이 작업 전까지 기사가 구글에 색인되지 않습니다**

---

# 1. 증상

Google Search Console → 색인 생성 → 페이지 리포트

| 사유 | 페이지 수 |
|---|---|
| 사용자가 선택한 표준이 없는 중복 페이지 | 8 |
| 'NOINDEX' 태그에 의해 제외 | 3 |
| 적절한 표준 태그가 포함된 대체 페이지 | 2 |
| 발견됨 - 현재 색인이 생성되지 않음 | 16 |
| 크롤링됨 - 현재 색인이 생성되지 않음 | 4 |

3개월 실적: 총 클릭 3, 총 노출 18, 평균 게재순위 1.7

> 게재순위 1.7은 **노출만 되면 거의 1위**라는 뜻. 순위가 아니라 **색인이 병목**이다.

# 2. 원인 (확인 완료)

**모든 페이지가 canonical을 홈페이지로 지정하고 있다.**

실제 응답 확인 결과:

```
GET /                             → <link rel="canonical" href="https://www.sdtime.net">
GET /article/haeryong-launch-2026 → <link rel="canonical" href="https://www.sdtime.net">   ✕
GET /articles                     → <link rel="canonical" href="https://www.sdtime.net">   ✕
GET /info/recycle                 → <link rel="canonical" href="https://www.sdtime.net">   ✕
GET /legal/publisher              → <link rel="canonical" href="https://www.sdtime.net">   ✕
GET /board                        → <link rel="canonical" href="https://www.sdtime.net">   ✕
```

이는 구글에게 **"모든 하위 페이지는 홈페이지의 중복이니 홈만 색인하라"** 고 지시하는 것과 같다.
`중복 페이지 8건`, `크롤링됨-색인 안 됨 4건`이 전부 여기서 발생한다.

**원인 위치 추정:** `app/layout.tsx`의 `metadata` 객체에 `alternates.canonical`이 **고정 문자열**로 선언되어 있고, 하위 페이지에서 이를 덮어쓰지 않고 있음.

# 3. 원인 코드 찾기

```bash
# canonical 선언 위치 전수 검색
grep -rn "canonical" app/ src/ --include="*.ts" --include="*.tsx"

# metadata 선언 위치
grep -rn "export const metadata" app/ src/ --include="*.tsx"
grep -rn "generateMetadata" app/ src/ --include="*.tsx"

# metadataBase 설정 여부
grep -rn "metadataBase" app/ src/ --include="*.tsx"
```

`app/layout.tsx`(또는 공통 metadata 모듈)에서 아래 형태를 찾는다.

```tsx
alternates: {
  canonical: 'https://www.sdtime.net',   // ← 이것이 원인
}
```

# 4. 수정

## 4-1. 루트 레이아웃에서 고정 canonical 제거

**`app/layout.tsx`**

```tsx
export const metadata: Metadata = {
  metadataBase: new URL('https://www.sdtime.net'),   // 유지 (필수)
  title: {
    default: '해룡신문 — 순천시 해룡면 지역 인터넷신문',
    template: '%s · 해룡신문',
  },
  description:
    '순천시 해룡면 신대·선월·복성지구 소식을 전하는 지역 인터넷신문. ' +
    '지역 행정, 생활, 문화, 경제 소식을 가장 빠르게 전합니다.',

  // ❌ 아래 블록을 삭제한다
  // alternates: {
  //   canonical: 'https://www.sdtime.net',
  // },

  openGraph: { /* 기존 유지 */ },
  twitter: { /* 기존 유지 */ },
  verification: { /* 기존 유지 */ },
}
```

> **간단히 끝내려면 이 삭제만으로도 해결된다.** canonical 태그가 없으면 구글은 요청된 URL을 정규 주소로 간주한다.
> 다만 아래 4-2까지 하면 파라미터가 붙은 URL(`?utm_source=…` 등)까지 안전하게 정리된다. 권장.

## 4-2. 페이지별 canonical 지정 (권장)

`metadataBase`가 설정돼 있으므로 **상대경로**로 적으면 절대 URL로 자동 변환된다.

### 홈 `app/page.tsx`
```tsx
export const metadata: Metadata = {
  alternates: { canonical: '/' },
}
```

### 기사 상세 `app/article/[slug]/page.tsx`
```tsx
export async function generateMetadata(
  { params }: { params: Promise<{ slug: string }> }
): Promise<Metadata> {
  const { slug } = await params
  const article = await getArticle(slug)   // 기존 조회 함수 사용

  if (!article) return {}

  return {
    title: article.title,
    description: article.summary ?? article.subtitle ?? undefined,
    alternates: { canonical: `/article/${slug}` },
    openGraph: {
      type: 'article',
      title: article.title,
      description: article.summary ?? undefined,
      url: `/article/${slug}`,
      publishedTime: article.published_at,
      modifiedTime: article.updated_at,
      images: article.cover_image
        ? [{ url: article.cover_image, width: 1200, height: 630 }]
        : undefined,   // 없으면 layout의 기본 og-image 상속
    },
  }
}
```

### 목록·정적 페이지
각 `page.tsx`에 자기 경로를 지정한다.

```tsx
// app/articles/page.tsx
export const metadata: Metadata = { alternates: { canonical: '/articles' } }

// app/info/recycle/page.tsx
export const metadata: Metadata = { alternates: { canonical: '/info/recycle' } }

// app/legal/publisher/page.tsx
export const metadata: Metadata = { alternates: { canonical: '/legal/publisher' } }

// app/board/page.tsx
export const metadata: Metadata = { alternates: { canonical: '/board' } }
```

**적용 대상 경로 목록**
```
/                      /articles              /articles/local
/articles/admin        /articles/people       /articles/life
/article/[slug]        /info                  /info/recycle
/info/civil            /info/directory        /info/facility
/board                 /district              /orgs
/market                /tips                  /recruit
/ads/apply             /reporters             /reporter/[id]
/legal/publisher       /legal/youth           /legal/ethics
/legal/correction      /legal/privacy         /legal/terms
```

### 카테고리·검색 등 파라미터 페이지 주의
`/board?cat=question` 같은 쿼리 파라미터 URL은 **파라미터 없는 기본 경로**를 canonical로 지정해 중복을 막는다.

```tsx
// app/board/page.tsx — cat 파라미터가 있어도 canonical은 /board 고정
export const metadata: Metadata = { alternates: { canonical: '/board' } }
```

`/search`는 색인할 이유가 없으므로 noindex 처리한다.

```tsx
// app/search/page.tsx
export const metadata: Metadata = { robots: { index: false, follow: true } }
```

# 5. NOINDEX 3건 확인

서치콘솔의 `'NOINDEX' 태그에 의해 제외 3건`이 **의도한 것인지** 확인한다.

```bash
grep -rn "noindex" app/ src/ --include="*.ts" --include="*.tsx"
```

- `/admin`, `/login`, `/me`, `/onboarding` → **정상.** 그대로 둔다
- 기사나 생활정보 페이지에 걸려 있다면 → **제거**

`robots.txt`는 현재 정상이다. 변경 불필요.

```
User-Agent: *
Allow: /
Disallow: /admin
Disallow: /me
Disallow: /onboarding
Disallow: /login
Disallow: /auth/
Sitemap: https://www.sdtime.net/sitemap.xml
Sitemap: https://www.sdtime.net/news-sitemap.xml
```

# 6. 사이트맵 점검

현재 `sitemap.xml`에 URL 23개가 있으나 `<lastmod>`가 없다. 추가하면 재크롤 유도에 유리하다.

**`app/sitemap.ts`**

```ts
import type { MetadataRoute } from 'next'

export const revalidate = 3600

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const base = 'https://www.sdtime.net'

  // 발행 상태 기사만 (임시저장 제외)
  const articles = await getPublishedArticles()   // slug, updated_at

  const staticRoutes: MetadataRoute.Sitemap = [
    { url: `${base}/`,              changeFrequency: 'daily',   priority: 1.0 },
    { url: `${base}/articles`,      changeFrequency: 'daily',   priority: 0.9 },
    { url: `${base}/info/recycle`,  changeFrequency: 'monthly', priority: 0.8 },
    { url: `${base}/info/civil`,    changeFrequency: 'monthly', priority: 0.8 },
    { url: `${base}/info/directory`,changeFrequency: 'monthly', priority: 0.8 },
    { url: `${base}/info/facility`, changeFrequency: 'monthly', priority: 0.8 },
    // 나머지 정적 경로…
  ].map(r => ({ ...r, lastModified: new Date() }))

  const articleRoutes: MetadataRoute.Sitemap = articles.map(a => ({
    url: `${base}/article/${a.slug}`,
    lastModified: new Date(a.updated_at),
    changeFrequency: 'weekly',
    priority: 0.7,
  }))

  return [...staticRoutes, ...articleRoutes]
}
```

**확인 사항: 임시저장(draft) 기사가 사이트맵에 포함되면 안 된다.**

# 7. 함께 처리 권장 — 사이트 이름 표시

구글 검색 결과에 `해룡신문`이 아니라 `sdtime.net`으로 표시되는 문제. 홈페이지에 `WebSite` 구조화 데이터가 없어서 발생한다.

**`app/page.tsx`** (홈)

```tsx
const websiteLd = {
  '@context': 'https://schema.org',
  '@type': 'WebSite',
  name: '해룡신문',
  alternateName: ['해룡신문 sdtime', '순천 해룡신문'],
  url: 'https://www.sdtime.net/',
}

const orgLd = {
  '@context': 'https://schema.org',
  '@type': 'NewsMediaOrganization',
  name: '해룡신문',
  url: 'https://www.sdtime.net/',
  logo: {
    '@type': 'ImageObject',
    url: 'https://www.sdtime.net/icon.png',
    width: 512,
    height: 512,
  },
  foundingDate: '2026-07-27',
  email: 'rlaehdgo0301@gmail.com',
  telephone: '+82-10-3535-1221',
  areaServed: '순천시 해룡면',
  sameAs: ['https://blog.naver.com/sdtime0801'],
}

// JSX 안에
<script
  type="application/ld+json"
  dangerouslySetInnerHTML={{ __html: JSON.stringify(websiteLd) }}
/>
<script
  type="application/ld+json"
  dangerouslySetInnerHTML={{ __html: JSON.stringify(orgLd) }}
/>
```

**조건: 아래 셋의 이름이 일치해야 구글이 인정한다.**
- `WebSite` JSON-LD의 `name` → 해룡신문
- `og:site_name` → 해룡신문 (현재 적용됨 ✅)
- 홈 `<title>` 앞부분 → 해룡신문 (현재 적용됨 ✅)

# 8. 검증

배포 후 아래를 실행해 **각 URL이 자기 자신을 canonical로 갖는지** 확인한다.

```bash
for u in "/" "/articles" "/article/haeryong-launch-2026" "/info/recycle" \
         "/legal/publisher" "/board"; do
  printf "%-34s " "$u"
  curl -s "https://www.sdtime.net$u" \
    | grep -oE '<link rel="canonical" href="[^"]*"' | head -1
  echo
done
```

**기대 결과**

```
/                                  canonical="https://www.sdtime.net/"
/articles                          canonical="https://www.sdtime.net/articles"
/article/haeryong-launch-2026      canonical="https://www.sdtime.net/article/haeryong-launch-2026"
/info/recycle                      canonical="https://www.sdtime.net/info/recycle"
/legal/publisher                   canonical="https://www.sdtime.net/legal/publisher"
/board                             canonical="https://www.sdtime.net/board"
```

**추가 확인**

```bash
# 사이트맵 URL 수
curl -s https://www.sdtime.net/sitemap.xml | grep -c "<loc>"

# 구조화 데이터
curl -s https://www.sdtime.net/ | grep -o '"@type":"[A-Za-z]*"' | sort -u

# 기사 페이지 NewsArticle 유지 확인
curl -s https://www.sdtime.net/article/haeryong-launch-2026 | grep -c 'NewsArticle'
```
